📊

Xuất File Excel Đồng Bộ

Tải về file Excel chứa toàn bộ học sinh, học phí, bài tập, bài giảng vừa chỉnh sửa

File tải về có cấu trúc 5 sheet chuẩn: Học Sinh, Học Phí, Bài Tập, Bài Giảng, Cấu Hình Bảo Mật. Thầy chỉ cần lưu đè vào file Quản lý học sinh.xlsx trên máy tính để lưu trữ lâu dài.

💾

Tải File data.json

Tải tệp JSON dữ liệu chứa các mã băm bảo mật SHA-256

Thầy có thể sao chép file data.json tải về này dán vào thư mục docs/data.json của dự án rồi chạy git commit & push lên GitHub Pages.

🔄

Khôi Phục Từ Máy Chủ

Xóa các thay đổi tạm trên trình duyệt và nạp lại từ data.json

Dùng khi thầy vừa chạy script sync.bat trên máy tính và muốn cập nhật lại toàn bộ bảng điều khiển về trạng thái đồng bộ mới nhất từ Excel.

⚡ Hướng dẫn cập nhật 1-Click bằng file `sync.bat`:

  1. Sau khi tải file Excel hoặc chỉnh sửa trực tiếp file Quản lý học sinh.xlsx trên máy tính, nhấn Ctrl + S để lưu.
  2. Nhấp đúp chuột vào file sync.bat trong thư mục D:\0.CP\WebHocTap.
  3. File script sẽ tự động mã hóa bảo mật, cào lại bài nộp MarisaOJ và hỏi bạn có muốn tự động PUSH lên GitHub Pages không. Gõ Y để hoàn tất!
